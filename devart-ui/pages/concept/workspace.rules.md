# Shared workspaces — locked rules

Source brief: Claude Doc «Дизайн: Shared workspaces, фаза 1» (Victor, 2026-09-25; epic AIINS-1852;
design tasks AIINS-1858 / 1866 / 1873 / 1892 / 1887, history 04 / AIINS-1882). Patterns borrowed from
the AI connectivity workspaces prototype where they fit (its list, the opened workspace, PickRow).

| # | Rule |
|---|---|
| 1 | **Existing elements first.** Every piece is DevartUI or an existing kit component; what is new lives in the kit once: Workspaces (store, WsNotice, WsSharedBy, WsSearch), WsList, WsOverview, WsMembers, WsConnections, WsMetrics, WsFiles, WsDialogs, PickRow, WsEmail. Repeated pieces are candidates for design DevartUI (PickRow, the list search). |
| 2 | **Off by default on approved pages.** `?ws=1` (review switch Workspaces) turns the feature on; without it every approved page renders as approved. The new pages (`concept/workspaces.html`, `concept/workspace-emails.html`) are the feature and always on. |
| 3 | **One person, one world.** They own some workspaces and were invited to others; the role is each workspace's — no Owner / Member switch. Review switches are live and independent (no reload, nothing made on the way is lost): Workspaces · Plan (Paid · Trial · Free) · Invited (Active · Blocked) · Data (Workspaces page) · Overview (an opened workspace) · Names · Invitation (chat) · Email (emails page). Only where they act. |
| 4 | **Workspaces in the sidebar** — a nav row under New Chat → `concept/workspaces.html`. The list and an opened workspace are one page (`?w=`), as in AI connectivity. |
| 5 | **The list**: title action Create Workspace (round); search; FilterChips All · My Workspaces · Shared (only when there are both; switch Shared: Tabs → My Workspaces · Shared tabs); the count line in one 44px slot (DevartUI MetaRow 44px and ListSelectionBar 37px differ); only own rows tick (an invited row's checkbox is disabled: "Only the owner can delete it"); 20 + Load more; empty / no-match StatusViews. Invite / Add Connection / Share Files from the list open the dialog in place, and only once done the page goes to that workspace's tab. |
| 6 | **An opened workspace**: Owner — Overview · Connections · Metrics · Members · Files (Metrics: what its connections share with it, read-only, managed on the Metrics page); invited — Overview · Connections · Metrics · Files (everyone is listed on Overview). Below 640px the tab strip scrolls sideways (no scrollbar). Read-only for a Member: every management control is absent, not disabled. The title action follows the tab. |
| 7 | **Overview tiles act**: with something in it the gear opens that tab; with nothing yet it is "+" (add the first one in place). Locked while Blocked. Metrics has no action (they come with their connection). Overview has two layouts to compare (switch Overview: Row · Grid). Connection rows open Connection Details in place. |
| 8 | **Members is one list** with search, All · Members · Invited and statuses: invitations first, then the Owner, then members. An invitation row: the email + "Expires in N days" under it, the Status column the badge alone (Invited · Can't be accepted now while Blocked — not cancelled). No people count. The Owner has no actions. |
| 9 | **Search where a list is long by nature** — Metrics, Files, Members (and the Workspaces list); not on Connections (as My Connections, user 2026-10-19). Metrics also has All · Built-in · Custom; Files All · Artifacts · Uploaded, Select all and bulk actions (Owner: Download · Stop Sharing; Member: Add to Chat · Download). |
| 10 | **Adding a connection** shows where else it is shared, no re-auth; one with metrics asks first: "N metric definitions will become visible to <ws>" (Back · Cancel · Add); without metrics it is added at once. No per-metric ticks. |
| 11 | **Where what is shared shows — three options to compare** (review switch Shared, on Data Sources, Metrics, Files and the Workspaces list): **Tag** — in the person's own list, tagged Shared; **Tabs** — a Shared tab of its own (My Connections / My Metrics / My Files / My Workspaces · Shared; no tag inside it); **Workspaces column** — the one list, no tag. Whatever the option, a Workspaces column shows where one's own is shared into and where a shared one comes from; the author is not shown by default (the details panel names them). One item shared from several workspaces is one row, its workspaces "Marketing · Brand". Every workspace name mentioned links to its page. Rows keep one height — no captions under names. With anything shared the list is never the empty state; Hide shared (Metrics, Files) shows one's own alone. A shared metric opens Metric Details read-only (no switch, no footer). |
| 12 | **One family of "unavailable"**, every one fixed by a plan and leading to Manage plan: unavailable on your plan (Member's Free — rows visible with the plan's padlock, a notice above), workspace unavailable (Blocked — muted rows + Ask <Owner> to Renew, an email to the Owner), Create Workspace without the module (locked → Pro). Nothing reads as deleted. |
| 13 | **Blocked, Owner**: the notice with Upgrade to Pro in its sentence; Invite / Add / Share shown locked (the one exception to "absent"); Remove, Revoke, Stop Sharing, Delete still work. **Restored** is confirmed once ("Everything is where it was"). |
| 14 | **The trial heads-up** (Plan Trial) names what becomes unavailable — own workspaces for members, the counts of what is shared — as a hint, dismissible, with See plans. |
| 15 | **Chat**: own + shared connections in one list (shared ones with their workspace under the name); unavailable-on-plan and Blocked ones are not offered. The invitation shows above the hero after any sign-in: pending (Accept Invitation) · another address · expired · workspace unavailable. |
| 16 | **Disconnect** of a shared connection warns "Shared into Sales and Support" (no member count) and that it must be added again after reconnecting; it leaves those workspaces. **Create metric** warns while typing when the alias is shared already (theirs wins @revenue, the shared one stays @revenue__a3f9c1). **Delete Account** lists the workspaces deleted with it. |
| 17 | **Long names** (switch Names): one-line places truncate with the full text in a tooltip; dialog titles, notices, toasts and the emails wrap. Names have no invented limit. |
| 18 | **Emails** (`concept/workspace-emails.html`): the invitation (who, which workspace, sign in or create an account with this email, the expiry) and the renewal request a Member sends the Owner (why members lost access, nothing deleted, Upgrade Plan). |
| 19 | **Adding from where the item lives**: a connection’s ⋮ on Data Sources has Share via Workspace (locked while the person's workspaces are Blocked), a file's ⋮ on Files has Share via Workspace — the same picker (workspaces it is not in yet, + Create Workspace in place), a connection with metrics then asks first ("N metric definitions will become visible to …"). Switching tabs never moves the table: My and Shared tabs keep the same columns and the same slot above the table. |
| 20 | **Who shared it is its own review switch** (Owner: Hidden · Shown — the brief: who shared it and from which workspace, everywhere): Shown → an Owner column on Data Sources and Files ("You" / the owner), "Olena Petrenko · Marketing" on the metric group and the chat picker row. The workspaces show either way. |
