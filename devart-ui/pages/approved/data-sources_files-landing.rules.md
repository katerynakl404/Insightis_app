# Data Sources · Files — rules added since the archive

The locked rules of the original stay in `legacy-html/page-changes/data-sources_files-landing.md`;
this file records what changed after it.

| # | Rule |
|---|---|
| 1 | **A file has no Rename** (user, 2026-10-20: «забирай — його не буде» — supersedes rules 24 and 29): the row ⋮ is Add to Chat · Download · Delete (+ Share via Workspace after Add to Chat with workspaces on); no Rename file dialog, nor a Rename in the preview or a details panel. |
| 2 | **The preview's head without a one-item ⋮** (user, 2026-10-20: «не пхай один екшен в 3 крапки»): with Rename gone, Delete alone is a red icon (IconButton destructiveTertiary), first in the head — Delete · Add to Chat · Download · Close; a ⋮ only when two or more are left. |
| 3 | **No bulk Add to Chat** (user, 2026-11-27: «там взагалі кнопки не мало бути — ні на файлах ні для власника ж її нема»): a chat takes one file, so Add to Chat lives only in a file’s ⋮ and its preview; the selection bar of the Shared list (and of a workspace one was invited to) offers Download alone, as Files and the owner offer no Add to Chat in bulk either. |
